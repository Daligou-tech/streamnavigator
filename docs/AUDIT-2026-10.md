# StreamNavigator whole-site audit, 2026-10-10

Follows the per-product audits in this folder (2026-09-08 to 09-20). Those checked each product's
promise against its engine; this one checks the shared foundations and whether money can flow.
Checked against the code, live Stripe (read-only), Supabase and Vercel. All 91 test suites pass.

## Findings

1. **Report generation has been down since 2026-09-13 and the site still took orders. FIXED.**
   The last report attempts (2026-09-20) failed with "Your credit balance is too low". The only
   live payments ever taken were test purchases by the owner, so no customer was affected, but any
   new customer would have paid, waited 24h and been auto-refunded. `api/navigator-intake.js` now
   checks the provider before checkout (`api/_lib/provider-health.js`, 1-token probe, cached 10 min)
   and refuses with "temporarily unavailable, you have not been charged" while the account is out
   of credit. Only billing refusals close the gate; any other failure lets the sale through.
   *Owner action:* top up the Anthropic balance; sales reopen within 2 minutes on their own.

2. **Two products cannot be bought.** `/streaming` ($19.99/yr) and `/subscriptions` ($29) still have
   `REPLACE_WITH_` placeholder buttons (safely unclickable) because their Payment Links were never
   created. Needs Stripe write access (the connector used for this audit is read-only).

3. **Two retired Payment Links are still live in Stripe:** StreamNavigator Pro $4.99/mo
   (`plink_1U6Ie6H9DnCfGBIZwuRsRcpy`) and Family $8.99/mo (`plink_1U6Ie6H9DnCfGBIZpyylQEqI`).
   Anyone with the URL can still subscribe at prices no longer sold. Deactivate them (needs write access).

4. **Household sharing has no database.** The $19.99/yr plan promises "Everyone in the household,
   one price", and the dashboard calls `household-summary`, `invite-household-member` and
   `remove-household-member`, but the `households` and `household_members` tables do not exist in
   production. Every household action errors. Must be built (or the line removed) before finding 2
   is fixed and the plan goes on sale.

## Checked and sound
- Every API endpoint is protected: cron jobs by `CRON_SECRET`, Stripe webhooks by signature,
  account actions by Supabase session, submissions by per-submission access token, test endpoints
  by `NAVIGATOR_ADMIN_SECRET`.
- Failed paid reports are refunded automatically (`process-refunds`, four guards before money moves).
- No runtime errors in Vercel in the last 7 days.
